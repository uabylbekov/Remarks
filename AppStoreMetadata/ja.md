## Description
```
Remarksは、iPhone・iPad・Mac向けの高速なネイティブMarkdownメモアプリです。文章執筆からコード、数式、図表まで美しく整理できます。

買い切り型・サブスクリプションなし・アカウント不要
メモはあなたのデバイスとiCloudにのみ保存され、プライベートに同期されます。

技術メモにも日々の記録にも
・見出し、リスト、チェックリスト、引用、リンクに対応したライブプレビューMarkdownエディタ
・シンタックスハイライト対応のコードブロック（Fira Code、JetBrains Mono、IBM Plex Mono内蔵、合字・ライト／ダークテーマ対応）
・KaTeXによるLaTeX数式レンダリング
・Mermaid記法による図表のリアルタイム描画
・行・列を直感的に編集できるネイティブ表機能
・写真・ファイル添付およびMarkdown書き出し

Appleエコシステムに最適化
・階層フォルダ、タグ、ピン留め、高速検索、30日間の「最近削除した項目」復元
・Spotlightとショートカット／Siri連携（共有されるのはタイトル・プレビュー・タグのみで、本文全体は共有されません）
・オフライン対応＆iCloud自動同期
```
