## Description
```
Remarks 是一款專為 iPhone、iPad 與 Mac 打造的原生 Markdown 筆記 App，流暢優雅，同時滿足日常寫作與技術筆記需求。

一次買斷・無訂閱・免註冊帳號
你的所有筆記僅儲存在自己的裝置與個人 iCloud 中，安全私密，不經第三方伺服器。

專為技術與深度寫作設計
• 即時預覽 Markdown 編輯器，支援標題、列表、核對清單、引文、連結與行內格式
• 程式碼區塊語法高亮，內建 Fira Code、JetBrains Mono 與 IBM Plex Mono 字體，支援連字及淺色／深色主題
• 內建 KaTeX，精準渲染 LaTeX 數學方程式
• 直接於筆記內渲染 Mermaid 流程圖與圖表
• 原生互動式表格，輕鬆新增或刪除橫列與直欄
• 支援照片與檔案附件，並可乾淨輸出為 Markdown

完整融入 Apple 生態系
• 多層資料夾、標籤、釘選筆記、即時搜尋，以及 30 天「最近刪除」回復
• 支援 Spotlight 與捷徑／Siri（僅索引標題、預覽與標籤，絕不分享筆記全文）
• 完整支援離線使用，並透過 iCloud 自動同步
```
