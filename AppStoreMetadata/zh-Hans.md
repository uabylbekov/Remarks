## Description
```
Remarks 是一款专为 iPhone、iPad 和 Mac 打造的原生 Markdown 笔记应用，流畅优雅，兼顾日常写作与技术记录。

一次买断・无订阅・无需注册账号
你的所有笔记仅保存在你的设备和个人 iCloud 中，安全私密，无第三方服务器。

为技术与深度写作而生
• 实时预览 Markdown 编辑器，支持标题、列表、清单、引用、链接与行内格式
• 代码块语法高亮，内置 Fira Code、JetBrains Mono 与 IBM Plex Mono 字体，支持连字及深浅色主题自适应
• 内置 KaTeX，流畅渲染 LaTeX 数学公式
• 直接在笔记内渲染 Mermaid 流程图与图表
• 原生交互式表格，轻松增删行与列
• 支持图片与文件附件，并可整洁导出为 Markdown

深度融入 Apple 生态
• 多级文件夹、标签、置顶笔记、即时搜索，以及 30 天“最近删除”恢复
• 支持聚焦搜索与快捷指令 / Siri（仅索引标题、摘要与标签，绝不共享笔记全文）
• 完全支持离线使用，并自动通过 iCloud 同步
```
