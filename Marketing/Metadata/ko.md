## Description
```
Remarks는 iPhone, iPad 및 Mac을 위한 빠르고 깔끔한 네이티브 Markdown 노트 앱입니다. 글쓰기부터 코드, 수식, 다이어그램까지 한곳에 정리하세요.

한 번 구매로 평생 소장・구독 없음・계정 불필요
모든 노트는 사용자의 기기와 개인 iCloud에만 안전하게 저장되고 동기화됩니다.

기술 노트와 일상 기록을 모두 위한 기능
• 제목, 목록, 체크리스트, 인용구, 링크를 지원하는 실시간 미리보기 Markdown 에디터
• 구문 강조 코드 블록, 내장 고정폭 서체(Fira Code, JetBrains Mono, IBM Plex Mono), 합자 및 라이트/다크 테마 지원
• KaTeX 기반 LaTeX 수식 렌더링
• 노트 안에서 바로 렌더링되는 Mermaid 다이어그램
• 행과 열을 손쉽게 편집할 수 있는 네이티브 표
• 사진 및 파일 첨부와 깔끔한 Markdown 내보내기

Apple 생태계에 최적화
• 하위 폴더, 태그, 노트 고정, 빠른 검색 및 30일 최근 삭제된 항목 복원
• Spotlight 및 Siri/단축어 연동 (제목, 미리보기, 태그만 사용하며 본문 전체는 절대 공유되지 않음)
• 완벽한 오프라인 지원 및 iCloud 자동 동기화
```
